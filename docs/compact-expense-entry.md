# 日常入力と定期支出の確認を簡潔にする

2026-09-18。最初のゴール「支出を無理なく登録し続ける」を優先する改善。本番公開済み。公開結果は末尾を参照する。

## 日常の新規登録

- カテゴリ、金額、内容を先に入力する順番を維持する。
- 支払元、購入・支払いをした人、誰のための支出かは必須のまま。家計の既定支払元、ログイン本人に対応する人物、家族を初期選択し、選択内容を簡潔な一覧で表示する。鉛筆ボタンから選び直せる。
- 資金の持ち主と精算の扱いを常に表示する。個人払いの全額立替は、返す側・受け取る側・対象額も表示し、金額の変更に追従する。購入者と資金の持ち主を混同しない。
- 未設定、要確認、個別設定、一部額の立替、停止済みの参照先は支払情報を省略しない。既存支出の編集も従来どおり詳細入力で開く。折りたたみ可否は表示上の判断だけであり、サーバーの認可・検証を代替しない。
- 日付は今日を表示し、鉛筆ボタンから日付指定・月のみを変更する。カレンダー起点の入力や複製は渡された日付精度を保持する。月から日へ切り替える際、覚えていない日を自動補完しない。
- 日付/月入力はモードごとに別の入力要素を使う。モード往復後に画面の値とReactの値がずれることを防ぎ、保存値まで検証する。
- 保存失敗時の入力、再送ID、連続入力、入力破棄確認、狭い画面の保存ボタンを保持する。下書きを新しくブラウザの永続ストレージへ保存する変更はない。

## 定期支出の当月確認

- 確定対象の年月、カテゴリと費用区分を示し、金額・支払情報・日付を中心に表示する。日付は定期設定由来なので、当月確認では最初から入力欄を表示する。
- 基準額は基準額として、前回額は前回の確定額として明示する。毎回入力や前回実績なしは金額を空欄にし、本人の入力を必須とする。サンプル除外・仮設定の確認は既存の仕組みを維持する。
- 「詳細を編集」でカテゴリ、内容、費用区分、メモも当月だけ変更できる。折りたたんでも値を失わず、変更した内容・区分・メモを表示する。
- 既存の支出編集コンポーネント、定期確定API、バージョン検証、再送・重複防止を再利用する。当月の確定で定期設定を書き換えない。スキップ・延期・登録済み支出との関連も変更しない。

## 前月比較

- 比較対象を折りたたみの外へ表示する。今月は「今月ここまでの記録と前月全体の比較」と示し、割合を表示しない。差額は「前月総額との差」とする。
- 将来月も登録済み支出と前月全体の比較として割合を表示しない。過去月は月全体同士の差額・割合を維持する。
- 日割り予測・同日比較ではない。合計・サンプル注意表示・まとめ記録の残額計上は変更しない。

## 変更しない境界

DB、migration、共有Auth、環境変数、家計参加者、API、CSV、v7バックアップ形式を変更しない。本番の支出・精算・定期設定やサンプルを編集しない。他アプリとPreviewのデータ・権限も変更しない。
