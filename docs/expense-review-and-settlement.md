# 支出の振り返り・一括精算・仮設定の確認

2026-09-13の改善。7月/8月のサンプル投入後に確認した課題を対象にする。本番公開済み。公開結果は末尾を参照。

## 定期支出

- 未登録の件数、基準額の合計、前回額/毎回入力の件数を分ける。従来「変動額」の件数から前回額が漏れていた表示を修正。
- この月の一覧は確認待ち、確認日前、登録済みの順。過去の確定/スキップは消さず、停止・2か月周期・延期も既存ルールを維持する。
- `【仮】` の名称またはサンプルbatchを含む設定は、未確認のまま確定できない。「仮設定を確認」から金額/支払元/確認日を確認し、確認済みチェックを付けて保存する。チェックで既知の仮ラベル/定型メモだけを取り除く。過去支出は変更しない。
- 設定が確認済みでも、前回額にはサンプル支出を使用しない。実績がなければ金額欄は空で必須入力。基準額も毎月確認・変更でき、自動確定しない。
- 実際の契約額・支払元は本人が確認する。今回の公開作業で仮の金額を実額と推測して置き換えない。

## 一括精算

- 既存の立替一覧でチェックし、同じ返す側/受け取る側だけを最大50件選ぶ。ページをまたぐ選択は保持し、表示条件変更で解除する。部分精算済みの支出も残額だけを対象とする。
- 日付、共通メモ、件別内訳、合計、返金済みチェックを確認して保存。合計はスクロール後も保存ボタン付近に表示する。実際の送金・銀行接続・相殺は行わない。
- まとめて登録するのは選択した全支出の残額。今回の一括操作では任意の一部額を配分しない。一部返金は既存の支出ごとの精算画面を使う。
- サーバーで本人確認・家計参加・同一方向・バージョン・全残額を再照合。家計lockと行lockの下、1トランザクションで全件を保存する。途中失敗は全件ROLLBACK。APIはOrigin検査、no-store、厳密入力検証を維持する。
- 各精算IDを再送時にも保持し、全件の同一内容のみ再送を許可する。一部だけ保存済み/取消済み/内容相違は409。競合時は入力を保持し、一覧を更新して明示的に選び直す。
- 既存settlementsへ支出ごとに保存し、実際の記録者・変更履歴・CSV・v7バックアップに残す。取消は支出ごとの既存画面で行う。一括取消・自動相殺は未実装。

## サンプルとの区別

- 既存の85サンプルや9仮設定は削除せず、既存9月支出・住宅ローンを保持する。
- 精算一覧の未精算額はサンプルを除外し、除外件数/金額を別表示。「サンプルも表示」で閲覧できるが、個別/一括とも新しい精算登録を拒否する。過去の精算取消は妨げない。
- 判定は `famfi-sample-summer-2026-v1` メモと `【サンプル】` 接頭辞による誤操作防止。編集可能な表示上の目印であり、RLS/家計認可や改ざんできないデータ分類ではない。目印をまとめて削除して実支出扱いにしない。
- 支出合計と比較はサンプルを含む従来の計上を維持し、比較欄でサンプルを含む旨を表示する。バックアップ・履歴・既存CSVから記録を消さない。撤去時は [サンプル手順](sample-data.md) のID・履歴・参照制約を確認する。

## 前月比較

- 月全体の前月差、割合、固定/変動/特別/未分類の増減、増加した親カテゴリ上位3件。支出一覧の検索/絞り込みには連動せず、月全体同士を比較する。
- 子カテゴリを親へまとめる。明細とまとめ記録の未整理残額だけを計上し、予定・メモ・精算は加算しない。月またぎの明細は支出月、未整理残額はまとめ記録の計上月という既存仕様を維持する。
- 前月に記録がないときは未入力の可能性があるため増減を算出しない。前月0円の除算はしない。2000年1月は範囲外の前月を照会しない。
- 当月は月途中と前月全体の比較と明示。サンプルを含む比較から実際の家計を評価しない。将来の支出予測、同日比較、予算/銀行残高は未実装。
