# 最初のゴール: 日々の支出管理

まず本人1人がスマホから利用する。家族との共有は別段階とする。

## 完成条件

- メール認証でログインし、famFi の利用許可を持つ本人だけが使える。
- 円単位の正の整数、日付または年月、カテゴリで支出を記録する。内容とメモは任意。
- 月別の一覧、カテゴリ別内訳、合計、編集、削除が実データで動く。
- 再読み込み・別端末でも記録が残る。
- 未ログイン、別ユーザー、別アプリからの取得・変更を拒否する。
- CSV出力と、バックアップ・復旧の手順を用意する。
- 本番とスマホで確認し、サンプル金額を本物として表示しない。

## 優先度

1. 認証、利用許可、共有DB内の専用テーブル・権限。
2. 支出CRUDと永続化。二重保存と編集競合の防止。
3. スマホ入力、月別集計、カテゴリ絞り込み、CSV出力。
4. 権限・操作テスト、バックアップ復元確認、本番反映。
5. 利用開始後: 親子カテゴリ・カテゴリ管理、入力テンプレート、固定費。旧試作と本番MVPの違いは [日付・カテゴリ仕様](expense-input-and-categories.md) を参照。
6. 後続: 収入、予算、家族共有、CSV取込、詳細分析。

レシピ、家事、予定などの試作コードは残すが、最初の本番版には公開しない。
共有DBの正本は `personal-apps-infra`。実施済みの状態は同リポジトリと
`docs/shared-database.md` に記録する。
